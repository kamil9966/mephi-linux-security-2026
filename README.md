# Домашнее задание №1

Номер: M265240. ОС: РЕД ОС 8.0.3.

1. Создан user1 с UID 1234 и группой students. Срок действия пароля - 90 дней (каждые 3 месяца).
2. Найдены файлы с set-UID и процессы с эффективным UID 0 и реальным UID обычного пользователя.
3. Копии cat в /home/user1/cat установлен set-UID. Она читает закрытый файл /root/root-only.txt.
4. Копии chown в /home/user1/chown выдана cap_chown=ep. Она меняет владельца /home/user1/test.txt на root.
5. В sudoers пользователю user1 разрешена команда /usr/bin/date -s через sudo.
6. История, скриншот, stat, getcap, системные файлы и результаты поиска приложены.
